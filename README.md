🎨 Random Color Generator

Random Color Generator is a responsive web application made with HTML, CSS and JavaScript. It generates 30 totally random colors along with their color codes. Every time the project is refreshed, new set of colors appear, which makes the website useful for exploring different color palettes all the while practicing efficient JavaScript and DOM manipulation. 

The project development includes HTML structure, with CSS3 for styling and the flexbox layout, with ES6 javascript used to generate the colors and their hexadeciaml codes. No external liberaries or frameworks were used. 


For running the project, launch the index.html file from the repository in your preffered browser. If you are using VS code, you can also use the live server.
Demo Link: https://random-color-generator-three-azure.vercel.app/

I learned a lot of stuff from this project, including, how to create HTML files dynamically with Java and loops, working with DOM, using Math.random() and Math.floor() for generating random color codes and applying them in the boxes. 

In the future, I plan to add features such as a button to generate a new set of colors, one-click copying of hexadecimal color codes, automatic text color adjustment for better readability, the ability to choose the number of generated colors, and support for saving favorite colors using localStorage.
